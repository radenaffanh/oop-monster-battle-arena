# Monster Battle Arena

Two-player turn-based monster battle game in C++ using abstract classes, inheritance and polymorphism.

## Features

- Three monster types (Fire, Ice, Earth) derived from an abstract Monster class
- Players pick a monster and take turns attacking
- Status effects that reset after each turn
- Method overloading and pure virtual (interface) methods

## How to run

```bash
g++ monster_battle_arena.cpp -o monster_battle_arena
./monster_battle_arena
```
